# Prove-It Clock — Rules

The Clock scores crypto projects' promises against measured reality. Market cap is never an input — price is not evidence of utility.

**Versioned methodology.** Every scoring change ships as a new versioned methodology file. Diffs are public. Silent rewrites are a defect, not a feature.

**Append-only history.** New versions add new snapshots. Past snapshots are never rewritten.

**The observer effect.** Publishing scores can move markets. The Clock measures reflexivity risk in others; it must not become a source of it. Influence is a liability to be managed, not a goal. Safeguards: append-only history, versioned methodology, publisher holdings disclosure, no per-project tuning, no paid placement. If projects ever optimize for Clock scores instead of real utility, the methodology changes — publicly, as a new version. (Goodhart's law is a design constraint, not a footnote.)

**No tuning.** Algorithms calculate; nothing is tuned per project. Every number comes from methodology config + observations + versioned analyst seeds.

**No paid placement.** Sponsorship never affects rankings. Ever.

**Publisher disclosure.** Alex Borsody discloses positions in and promotional interest around scored tokens (`app/data/disclosures.json`). Entries are marked UNCONFIRMED until position details are verified. Undisclosed holdings would make this a marketing operation, not a measurement one.

**Missing data is labeled, never invented.** Gaps become `unavailable` components that reduce confidence — never zero-filled, never hidden.

**Provisional seeds.** Low-confidence project seeds ship flagged as PROVISIONAL and score-capped, not padded with guesses.
